## Pass 2 — Defender

The final asynchronous application guard checks controller lifetime, post identity, connection, settings revision, media revision, visibility, and the current fingerprint. The targeted delayed-verdict probes support those defenses across the new whole-post behavior. Eligibility is checked before caption/media extraction; adding an editor makes direct extraction return excluded content. Whole-card replacement preserves the original display property and priority, while standalone media retains its separate footprint restoration. Removed covers reset completion state and allow the original to be restored and reconsidered.

Covering an image now pauses every eligible video in its post, and subsequent play events cannot restart an unchanged covered video. A changed stream can invalidate the old decision. Revealing covered content leaves playback under user control; automatic replay is not required by the approved contract. The game intentionally remains paused after returning to a visible tab, and a directly opened tab may show the dismissal screen instead of closing the tab. Both behaviors satisfy the approved pause and close requirements.

Keyboard scoring can complete the game quickly, but keyboard access is an explicit requirement. The target retains focus, native controls remain operable, completion and pause are announced, and reduced motion disables target movement and mascot animation. The code adds no game network calls, storage, permissions, or persistent reward state.

The portable kit's `manifest.json` is kit metadata, not the extension manifest; these files are intentionally different. Every shared game, font, image, and mascot stylesheet entry matches the extension archive byte for byte. The existing task review's Instagram alt regression is fixed and covered by a dedicated test; no remaining instance was established.
