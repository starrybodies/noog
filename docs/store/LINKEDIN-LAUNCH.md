# LinkedIn launch announcement

Noog is live on the Chrome Web Store. 🐈‍⬛

I built it because I wanted a little more say in what gets my attention online.

Noog is a free Chrome extension that replaces unwanted content with cats, nature, wisdom, or a little quiet. It checks images on your device and uses local rules for promotional captions. No account, API key, or subscription required.

The internet has enough things competing for our attention. I thought it could use more kitties.

This is an early release, and it will miss things. If you try it, I'd love to hear what works, what doesn't, and where you'd like it to go next.

Meet Noog: https://noog.symbai.studio/
